## Policy / 发布原则

Project-specific source is distinguished from licensed third-party source and unresolved external/mixed implementations. Applicable third-party notices and license texts remain. No repository-wide license is assigned. Public accessibility of author code does not establish a redistribution grant.

### Project-created / project-specific source

Files first introduced in this reproduction repository for study-specific preparation, analysis, verification, aggregation, plotting or orchestration, with no identified complete external implementation in the audited sources.

**This classification records repository provenance and does not make a broader legal authorship claim beyond the available evidence.** Bulk-upload history alone is not authorship proof. The combined review uses recorded first commits/dates, study-specific interfaces and purpose, whole-source comparisons, exact function comparisons and contiguous-text comparisons. In 83 inspected upstream Python files, the 74 recovered files had no identified complete implementation match, no exact external function of at least eight lines, and at most three consecutive nonblank/nonimport matching lines. This is a bounded comparison, not an exhaustive originality search.

恢复文件标为 `PROJECT_CREATED` / `project-specific implementation` / `No repository-wide license assigned` / `PROJECT_SOURCE_RETAINED` / `retain`。这些标签说明目前证据支持的项目来源，不是绝对原创版权声明。未找到外部来源本身不再被视为删除理由；实际识别到上游或混合来源、而完整文件再分发许可未确认的实现仍不公开。

## Required local source setup / 按工作流准备本地源码

The public repository includes project-specific preparation, analysis, verification, aggregation, plotting and audit scripts. Workflows depending on original-author or third-party source with unresolved redistribution permission require local source setup. Pure CSV statistics, ROC/confusion-matrix plotting, and preparation wrappers do not require private model implementations. They still need their documented inputs and Python packages.

公开的数据整理、统计和绘图代码可直接调用；涉及未公开模型、训练或评价实现时，才按具体任务准备源码。数据、权重、Python 依赖、历史完整记录是另外的前提，并不由源码检查工具提供。

```powershell
python code/run.py --list

python code/setup_third_party.py --check --workflow classification-exp1
python code/setup_third_party.py --private-source "D:/private/breastdm-reproduction-source" --workflow classification-exp1
# Optional inventory-wide check; NOT a prerequisite for every command:
python code/setup_third_party.py --check
# Initialization is allowed without any excluded source:
python code/local_generation.py init
```

On a clean public checkout, the full check reports **41** missing sources (13 canonical, 28 historical), rather than 116. Eight have existing original-author restoration recipes; 33 require exact privately held adaptations. A missing file gives exit code 2. `--workflow` and `--path` restrict both checking and restoration; restored project scripts are never setup requirements. [workflow_sources.json](provenance/workflow_sources.json) lists exact source prerequisites, including historical snapshot paths where scripts explicitly import/read snapshots. The historical 3D snapshot lacks package initializers, so standard Python resolution can use the staged canonical `src`/`train_utils` packages; checks include those unchanged canonical dependencies as well as explicitly read historical files. No import algorithm or historical source was changed. These checks do not establish availability of datasets, checkpoints, packages or completed-run evidence.

Restoration validates all requested inputs before writing, refuses differing existing files and escaping links, preserves exact baseline bytes, and never executes supplied source. Keep excluded source private and ignored; do not force-add it. Original-author downloads alone cannot recreate all project adaptations. Source setup does not grant permission.

`init` copies public tracked files and any already verified private sources to the ignored `.local/reproduction` workspace, refuses an existing destination, and needs no missing private sources. Alternatively initialize first and run its copied setup utility for only the desired workflow. Existing private copies are not upgraded automatically; keep a separate backup and use a fresh checkout for this documented initialization.

Classification manifest generation also records code/weight hashes through the existing evidence collector, so its two model/training source prerequisites and pretrained weights remain required. Full classification summaries verify historical completion records and checkpoint/source hashes; do not replace them with fabricated hashes. Use the standalone CSV summarizer for statistics without historical completion evidence.
