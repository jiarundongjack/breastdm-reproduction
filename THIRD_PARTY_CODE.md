# Third-party code provenance and redistribution

This is the authoritative file-level source policy for the current public `main`. Its machine-readable appendix is [source_inventory.json](provenance/source_inventory.json). The audit covers all **132 Python/source files** in baseline `e5d4b2b446971440b08422539ee532096c89e1b2`. SHA-256 values below identify baseline Git blobs, not filesystem newline conversions. Historical commits and releases are outside this cleanup.

## Policy / 发布原则

Project-authored code is distinguished from licensed third-party code and unresolved source. Licensed third-party implementations remain with source attribution, modification statements and complete license texts. Complete files whose redistribution permission is not established are absent from the public tree; links and hashes preserve the evidence chain. An original-author repository being public does not establish redistribution permission. No repository-wide LICENSE is assigned.

本轮区分原创、许可明确的第三方代码和来源待确认代码。许可明确的文件保留；许可不明的完整源码副本移出当前公开树，保留来源、哈希与本地恢复说明。公开可访问不等于已经明确允许再分发。本文件不为整个仓库套用统一许可证。

`PROVENANCE_UNRESOLVED` means authorship/permission has not been established; it does **not** assert plagiarism or that the project did not write a file. The project owner could not confirm authorship of experimental scripts. Upload authorship, filenames and unmatched similarity searches are not treated as proof of original authorship. Adaptations with an identifiable licensed base can still have unresolved additional authorship; the complete adaptation is conservatively excluded until clarified.

## Required local source setup / 必须先完成的本地源码准备

**A fresh public clone is not an executable reproduction bundle.** Preparation, training, inference, figures, summaries, historical audits and weight restoration commands that refer to removed scripts require local source setup first. This is a real dependency gap: unresolved reproduction adaptations have no verified public replacement. Downloading the original BreastDM repository alone is insufficient for the full workflows. Obtain the exact adaptations from your own existing private sources, or seek clarification/permission from their authors. Do not recover and republish unlicensed copies from historical Git commits or releases.

**公开仓库不能直接完成全部复现。** 数据整理、训练、预测、绘图、汇总、审计和权重恢复等命令，必须先恢复它们依赖的本地源码。原作者仓库只能提供部分文件，不能代替来源尚未确认的复现改编。完整恢复需要你自行持有的私有源码，或进一步向作者确认来源与许可。未具备这些源码时，相应工作流仍不可运行；下列工具不会下载代码，也不会替用户获得许可。

From the repository root (standard-library Python only):

```powershell
python code/setup_third_party.py --check
# Use your own previously acquired source tree, preserving repository-relative paths:
python code/setup_third_party.py --private-source "D:/private/breastdm-reproduction-source"
python code/setup_third_party.py --check
# Then follow the existing LOCAL_GENERATION.md commands:
python code/local_generation.py init
```

`--check` returns exit code 2 for missing/mismatched sources. Restoration validates the entire requested set before writing, refuses differing existing files and links escaping the supplied roots, and checks the exact restored SHA-256. Nothing is executed during restoration. Exact removed paths are ignored by Git; do not force-add them. The initializer explicitly copies verified restored sources into the ignored `.local/reproduction` workspace. If that private destination already exists, retain it as a private backup and use a fresh checkout/destination workflow; initialization never overwrites it. Existing private copies need the updated setup utility and inventory before using the updated local-generation entry point.

The inventory provides automatic upstream recipes for six `Models.py` snapshots, the PPV reference and one training-package import file. All other removed versions require a matching private source tree. We did not manufacture patches containing uncertain third-party source or reimplement models to bypass this limitation.
